# Integration Hub v0.1 Scope

Issue: `Gary0097/zhiyun-ai-platform#74`; capability: PRD feature 29.

Provide controlled CSV/JSON, HTTPS API and read-only SQLite connectors; explicit
dependency health; field mapping preview; persistent Run/Trace/error/retry
evidence; and confirmed Data Core commit bookkeeping. Credentials are referenced
by environment-variable name and are never stored. Direct external writes,
scheduled background sync and vendor-specific ERP/WMS adapters are outside v0.1.
